## TOP SECTION: COVER MODE TOUCH ZONES

[Your existing touch zone diagram fits here - the one you uploaded]

**Zones:**
- **Top 20%**: VOLUME UP (Gold/Yellow background)
  - Tap to increase volume
  
- **Left 25%**: SKIP BACK 15s (Dark Blue)
  - Tap to rewind 15 seconds
  
- **Center 50%**: PAUSE / SWIPE AREA (Dark Gray/Black)
  - **Tap**: Pause/Play
  - **Swipe ⬅️**: Previous track
  - **Swipe ➡️**: Next track
  - **Swipe ⬆️**: Show lyrics (if available)
  - **Swipe ⬇️**: Show track info
  
- **Right 25%**: SKIP 15s (Dark Green)
  - Tap to skip forward 15 seconds
  
- **Bottom 20%**: VOLUME DOWN (Dark Red/Maroon)
  - Tap to decrease volume

---

## MIDDLE SECTION: ADDITIONAL COVER MODE GESTURES

**Other Gestures (Center Area):**
- 👆 **Long press** (hold): Toggle lyrics display

**Keyboard Shortcuts** (when using browser/desktop):
- Space: Pause/Play
- ← Arrow: Previous track  
- → Arrow: Next track
- ↑ Arrow: Volume up / Lyrics page up
- ↓ Arrow: Volume down / Lyrics page down
- L: Toggle lyrics
- I: Show track info
- Shift+V: Toggle verbose mode (shows commands)

---

## BOTTOM SECTION: BROWSER MODE

**File Navigation:**
- 👆 **Tap track**: Play single track
  - Auto-switches to Cover Mode
  
- 👆 **Tap folder**: Open folder
  - Browse deeper into folder structure

**Context Menus** (Long Press):
- 👆 **Long press track**:
  - "Play this track" - Start from this track
  - "Play from here" - Play from this track onwards

- 👆 **Long press folder**:
  - "Play Folder" - Play all tracks in order
  - "Shuffle Folder" - Play all tracks randomly

**Navigation:**
- **[Cover] button**: Switch to Cover Mode (fullscreen album art)
- **[Browser] button**: Switch to Browser Mode (file explorer)
- **Back button**: Go up one folder level

---

## TIPS SECTION

💡 **Pro Tips:**
- First time? Enable **Verbose Mode** (Shift+V) to see commands as you use them
- Swipe gestures work best in the center area
- Touch zones are designed for one-handed tablet use
- Long press = hold for ~500ms (half second)
- Cover auto-updates when tracks change

📱 **For iPad:**
- Add to Home Screen for full-screen web app mode
- Works offline once loaded
- Supports iOS 9.3+ (tested on iPad 4)
